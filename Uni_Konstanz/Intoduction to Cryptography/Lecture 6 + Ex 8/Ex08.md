Second-preimage resistance: Informally, a hash function is said to be second-preimage resistant if given s and a uniform x it is infeasible for a PPT adversary to find x' != x such that H^s(x') = H^s(x)

(a) Formally define the security experiment corresponding to second-preimage resistance.

Hash-coll A,H(n)

A key s is generated by running KGen(1^n)

The adversary A is given s, and outputs x, x'. 

The output of the experiment is defined to be 1 if and only if x != x' and H^s(x) = H^s(x'). In such a case we say that A has found a collision
