# Ex 02
We explore what happens when the basic CBC-MAC construction is used with
messages of different lengths.

a) Say the sender and receiver do not agree on the message length in advance
   (and so Vrfyk (m, t) = 1 iff t = Mack(m), regardless of the length of m), but
   the sender is careful to only authenticate messages of length 2n. Show that
   an adversary can forge a valid tag on a message of length 4n.

2n message:

t0 = 0^n, t1 = MAC_k(m1), t2 = MAC_k(m2 xor t1) = t = MAC_k(m1,m2)

4n message:

m' = (m1, m2, m1 xor t, m2).

t'_0 = 0
t'_1 = MAC_k(m1) = t1
t'_2 = MAC_k(m2) = MAC_k(m2 xor t1) = t2 = t
t'_3 = MAC_k(t'_2 xor MAC_k(m1 xor t)) = MAC_k(t xor m1 xor t) = MAC_k(m1) = t1
t'_4 = MAC_k(t'_3 xor m2) = MAC_k(t1 xor m2) = t2 = t

So that is how Adversary can build a new valid tag t' for 4n message.
